# Sales Data Analysis (Excel Project)

## Objective

To analyze sales data in order to identify trends in product performance, revenue distribution, and monthly sales patterns.

---

## Tools Used
- Microsoft Excel

---

## Dataset Overview

The dataset contains sales records including product names, quantities sold, revenue, and transaction dates.

---

## Data Cleaning

- Removed duplicate entries
- Standardized date formats
- Checked for missing values
- Organized data into structured tables

---

## Analysis Performed

- Identified top-selling products
- Analyzed monthly sales trends
- Compared product category performance
- Calculated total revenue

---

## Key Insights

- Certain products consistently generated higher sales
- Sales showed variation across months indicating seasonal trends
- A small group of products contributed majority of revenue

---

## Skills Demonstrated

- Data cleaning in Excel
- Basic data analysis
- Chart creation and visualization
- Business insight interpretation
